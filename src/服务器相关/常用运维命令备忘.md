# 常用运维命令备忘

## 防火墙

```bash
firewall-cmd --state                                          # 查看防火墙状态
firewall-cmd --zone=public --add-port=52159/tcp --permanent   # 放行端口
systemctl restart firewalld                                   # 重启防火墙
```

## iptables

```bash
# 开放全部 TCP 端口（风险高，仅测试环境使用）
iptables -A INPUT -p tcp --dport 0:65534 -j ACCEPT
```

## tiktok-ws-server 服务

```bash
cd /data
nohup ./tiktok-ws-server > /dev/null 2>&1 &   # 启动
ps -aux | grep tiktok-ws-server               # 查看服务状态
kill -9 <PID>                                 # 关闭
```

## 系统路径说明

::: tip
`/usr/lib/python2.7/dist-packages` 是 Debian/Ubuntu 的 Python 库路径，CentOS 对应路径是 `/usr/lib/python2.7/site-packages`，注意区分系统再查找对应路径。
:::
