# S5 代理搭建

S5 代理的几种搭建方式汇总，按服务器系统选择对应方案。

## 方案一、一键脚本搭建（CentOS）

```bash
wget -q -N --no-check-certificate https://raw.githubusercontent.com/wyx176/nps-socks5/master/install.sh && chmod 777 install.sh && bash install.sh
```

## 方案二、Debian / Ubuntu 搭建

VPS 系统选择：**Debian 11 x64 / Ubuntu 20.04**

搭建步骤（共 7 步，完成 1 步后再执行下一个命令）：

```bash
# 1. 更新源
apt-get update

# 2. 安装 wget
apt-get install wget

# 3. 安装 sudo（运行命令的工具）
apt-get install sudo

# 4. 安装防火墙
sudo apt-get install ufw

# 5. 启动防火墙
sudo ufw enable
# 关闭防火墙
sudo ufw disable

# 6. 端口放行
sudo ufw allow 5555/tcp    # S5 端口
sudo ufw allow 18080/tcp   # 管理后台端口
sudo ufw allow 8025/tcp    # tcp 端口

# 7. 一键搭建 S5
wget -q -N --no-check-certificate https://raw.githubusercontent.com/wyx176/nps-socks5/master/install.sh && chmod 777 install.sh && bash install.sh

# 重启防火墙
sudo ufw reload
```

安装海外服务器客户端（IP 和 vkey 替换为实际值）：

```bash
-server=<服务器IP>:8025 -vkey=<vkey> -type=tcp
```

## 方案三、danted 搭建（Debian / Ubuntu）

### 一键安装

```bash
wget --no-check-certificate https://raw.github.com/Lozy/danted/master/install.sh -O install.sh
bash install.sh --port=5555 --user=socks --passwd=socks
```

### 服务管理

```bash
/etc/init.d/sockd {start|stop|restart|reload|status|state|adduser|deluser|tail|conf|update}
```

### 端口放行

```bash
sudo ufw allow 5555/tcp
```
